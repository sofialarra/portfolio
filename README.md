# Sofia Larraggione — Portfolio editorial (v3.11)

Web estática de una sola página, sin librerías. Funciona directo en GitHub Pages.

## Cómo funciona
- Portada → "¿Qué te gustaría ver?" → Modelaje, Creación de contenido, Actuación o Todo.
- Idioma ES / EN arriba a la derecha.
- Links directos para cada agencia (entran ya filtrados):
  - `.../#modelaje`
  - `.../#contenido`
  - `.../#actuacion`
  - `.../#todo`

## Publicar en GitHub Pages
1. Crear un repositorio nuevo en GitHub (ej. `sofia-larraggione`), público.
2. Subir todo el contenido de esta carpeta (Add file → Upload files).
3. Settings → Pages → Branch `main` / `(root)` → Save.
4. En 1-2 minutos: `https://TU-USUARIO.github.io/sofia-larraggione/`

## Cambiar fotos por originales en alta
Reemplazar el archivo de `img2/` con el mismo nombre, en `.webp`, ~2000 px de lado largo.
